# Levitaire v0.1.4

## 主要更新

- 文字工具栏新增简繁转换：提供「简体转繁体」与「繁体转简体」，词库按需加载，不影响启动速度。
- 工具栏按钮支持自定义顺序：可在设置页拖拽调整按钮排列，未调整时保持原有顺序不变。
- 便利贴支持插入图片：正文可直接插入图片，与便签一同持久化；删除便签时同步清理对应图片文件。
- 系统监控新增 GPU 面板：通过 PDH 性能计数器跨厂商采集显卡负载与专用显存占用（NVIDIA / AMD / Intel），无可用独立显卡时自动隐藏。
- 增强钉图 OCR 结果窗：区分「识别失败」与「后续操作失败」两类提示，补齐搜索引擎选择与翻译前置校验，失败时不再只留白屏。
- 增强计时与待办：改进分段计时、提醒触发与重复任务的时间推进，边界场景计算更准确。
- 增强语音朗读：重做播放请求与终态事件的状态机，连续朗读时不再出现状态错乱。
- 优化悬浮球、右键菜单与设置页：统一交互反馈与窗口定位，微调主题外观。

## 修复与稳定性

- 修复工具窗口关闭后状态未复位、焦点切换不稳定的问题。
- 改进全局快捷键、鼠标监听与窗口创建的边界处理，降低并发创建窗口时的竞态风险。
- 完善录屏、截图、OCR 与读屏流程中的资源清理与错误处理。
- 后端命令按功能域拆分为独立模块，降低单文件复杂度，便于后续维护。
- 补充文字工具栏、便利贴、计时、待办、设置与悬浮球等模块的测试覆盖，降低回归风险。

## 工程化

- 新增 CI 门禁：typecheck / lint / vitest / clippy / cargo test 在推送与 PR 时自动执行。
- 发版配置拆分：`ffmpeg.exe` 与 `onnxruntime.dll` 改由 `tauri.bundle.conf.json` 承载，基础配置只引用已入库资源，保证全新克隆可直接编译。
- 统一使用 npm 作为包管理器，移除遗留的 `pnpm-lock.yaml`。
