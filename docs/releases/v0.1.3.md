# Levitaire v0.1.3

## 主要更新

- 新增便利贴工具：支持多张便签、6 种预置纸色、实时编辑与持久化保存，长按工具栏可快速取用。
- 新增滚动导航工具：对当前网页或文档提供精确与百分比两种翻页方式，基于 UIA 滚动接口识别可滚动区域。
- 新增系统快捷工具集：集成取色器、滚动导航与工具切换的聚合面板。
- 计时工具新增节日与 24 节气标注：农历、节气均通过本地历法与天文黄经计算，不依赖网络或第三方库。
- 增强截图工作流：新增选区命中检测，完善标注工具与长期（滚动）截图捕获。
- 增强读屏能力：本地 OCR 与语音朗读流程更完整、稳定。
- 增强快速输入：输入窗口的编辑、提交与交互更顺滑。
- 优化悬浮球、工具面板与设置页：改进图标、交互反馈、窗口定位与主题外观。

## 修复与稳定性

- 修复工具窗口关闭后状态未正确复位、焦点切换不稳定等问题。
- 改进全局快捷键、鼠标监听与窗口管理的边界情况处理。
- 完善录屏、截图、OCR 与读屏流程中的资源清理与错误处理。
- 新增滚动导航、便利贴、计时、待办、设置与悬浮球等模块测试，降低回归风险。
