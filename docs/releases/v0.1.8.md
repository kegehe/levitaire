# Levitaire v0.1.8

## 主要更新

- **系统清理面板改版（布局 E「编辑索引」）**：顶部改为「构成卡」——可立即释放的大数字、隔离区暂存、磁盘可用量分行展示；有扫描结果时附带构成条与图例，按体积列出主要贡献项。清理项改为索引行：名称 ‥ 点线 ‥ 数值，数字列采用「大数值 + 小单位」排版。
- **构成条与标题同源**：两者都取上一轮扫描 / 清理报告，取消勾选不会再出现「2.3 GB 的标题下面只剩 200 MB 的条」；前 4 项之外汇总为「其他 N 项」，并只统计永久删除量（隔离量不算「立即释放」）。
- **系统清理的可读性修正**：隔离区「读取失败」恢复危险色；数值单位与图例字色提升到 AA 对比度；卷信息读不到时明确显示「未能读取磁盘信息」，不再伪装成「磁盘信息 / ——」；移除无样式的 `is-confirm` 类。

## 修复与稳定性

- **录制取消死锁**：`finish_recording_controls` 不再持生命周期锁做 `hwnd()` 的主线程往返；Esc 取消同时走钩子线程与前端 IPC 两条路径时，不再可能互等导致界面全僵。
- **便利贴丢字**：收起 / 删除请求失败时不再永久停写；删除请求在飞时跳过无意义的正文写入，失败后补一次落盘。
- **长截图丢行**：行复用只在「整段已存在」或「贴着拼接边」时生效，中间重复的空白行 / 表格行不会再吞掉新内容。
- **键盘钩子稳定性**：移除触发键回调里的落盘日志，避免钩子回调超时被系统静默卸载。
- **剪贴板**：文本写入改为先备好内存再清空剪贴板，分配失败时不会丢掉用户原有内容。
- **配置鲁棒性**：`from_hex` 改为按字节解码，配置损坏时不再在启动路径 panic；长路径拼接不再经过 `to_string_lossy`，非 Unicode 文件名不会被改写。
- **GIF 录制内存**：编码完成后不再在后端额外保留 raw + base64（64MB 的 GIF 原本会常驻约 149MB）。
- **长截图轮询**：状态查询增加 5s 超时与请求令牌，取消后立即停止轮询；主题订阅在卸载时正确取消。
- **贴图**：锁中毒不再让整个贴图功能陷入 panic。
- **杂项**：删除便利贴拖动路径里无效的窗口位置探测，按下即开始拖拽；OCR 结果复制失败给出可见提示。

## 工程化

- **最低 Rust 版本修正为 1.89**：下限由 `tauri-plugin-notification` → `notify-rust 4.18` 决定（不是 `ort`）。
- **CI 补强**：新增 `npm run build` 与 `npm run check:versions`（package.json / tauri.conf.json / Cargo.toml 三处版本一致性）。
- **发版脚本**：新增 `--notes-file`（UTF-8，支持多行、自动剥离 BOM 与 CRLF），版本号只读写 `[package]` 段，避免误改 `[dependencies.windows]` 的 `version`。
- **文档**：开发指南更新 Rust/Node 版本、日志路径、发布检查清单；README 补齐系统清理条目。
- **测试**：新增便利贴「收起失败后继续保存」与系统清理「构成条与标题同源」回归用例；Rust 623 项、前端 1234 项通过。
