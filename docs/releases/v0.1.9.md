# Levitaire v0.1.9

## 主要更新

- **截图选区改原生绘制（跟手）**：区域框选阶段的遮罩、选框与描边改由 Rust 侧的 GDI 原生层绘制，坐标由全局鼠标钩子直接喂进去，不再经过「pointermove → React 提交 → 合成 → 呈现」那条队列。实测 1800px/s 快速拖拽时，选框边缘相对光标的滞后从「固定 1 帧」降到 1px 量级（≈0–2ms），且不随拖拽速度增长。标注阶段（画布、工具栏、撤销栈、OCR 面板、长截图）仍在 WebView，行为与之前一致。
- **OCR 引擎自动回退**：PaddleOCR 不可用时（模型/字典缺失或损坏、ONNX 会话创建失败、缺少 onnxruntime.dll）自动切到 **Windows 内置 OCR**，两个引擎都不可用才报错；本地缺少 onnxruntime.dll 时不再尝试加载，避免卡在系统加载器里。
- **滚动导航并入通用工具面板**：取消独立的滚动导航悬浮窗，统一在「通用工具」内使用；置顶窗清单、capabilities 与自有窗口判定三处同步收敛，不再有第二份窗口名单。
- **长截图控制条自适应**：高度按内容（含警告行）量完再下发，重复尺寸不再反复重排窗口；居中后仍会夹到当前显示器工作区，屏幕比预览窗小时不会露出边缘。
- **钉图 OCR 结果窗**：关闭 / 隐藏时立即中止翻译流式请求，不让后台请求继续跑完消耗接口额度。
- **设置页 · 磁盘看门狗状态**：常驻后台任务的快照写回带序号，进入页签时发出的旧读取不会再覆盖较新的状态（此前会一直停在旧值，直到下一次周期检查）。
- **待办**：导入 / 导出 / 删除 / 延后等操作的提示改为带语义色与图标的通知条；一批控件补齐中文 aria-label。
- **失败可见性**：草图保存、文字工具栏的复制 / 打开浏览器失败时都会给出可见提示，不再只写后台日志。

## 修复与稳定性

- 原生选区层做了三重收口：前端 pointerup、钩子左键抬起（用抬起点补最后一帧）、pointercancel 与会话清理；准备失败或未就绪时自动退回 WebView 绘制，最坏情况等于没有这项优化。
- 松手到进入标注之间，原生层保持「冻结」在最后一帧，不会闪一下没有遮罩的裸桌面。
- 移除滚动导航独立窗口后，前端窗口表、capabilities 与自有窗口判定保持一致（有源码守卫测试覆盖）。
- 新增 3 条源码守卫测试：会话清理必须拆掉原生层、钩子喂坐标必须带「正在框选」门禁、松手必须同时停跟踪与冻结。

## 安装 / 升级

- 平台：Windows x64（Rust 1.89+ 构建）。
- 覆盖安装即可，配置与钉图/便签数据保留。
- 内嵌 OCR 模型缺失或 onnxruntime.dll 不可用时，OCR 会自动使用 Windows 内置引擎。
