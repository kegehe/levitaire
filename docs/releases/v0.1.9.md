# Levitaire v0.1.9

## 主要更新

- **截图选区改原生绘制（跟手）**：区域框选阶段的遮罩、选框、描边改由 Rust 侧的 GDI 原生层绘制，坐标由全局鼠标钩子直接喂进去，不再经过「pointermove → React → 合成 → 呈现」那条队列。实测快速拖拽（1800px/s）时选框边缘相对光标的滞后从「固定 1 帧」降到 1px 量级（≈0–2ms），且不随速度增长。标注阶段（画布、工具栏、撤销栈、OCR 面板、长截图）仍在 WebView，行为不变。
- **OCR 引擎自动回退**：PaddleOCR 不可用时（模型/字典缺失或损坏、ONNX 会话创建失败、缺少 onnxruntime.dll）自动切到 **Windows 内置 OCR**，两个引擎都不可用才报错；本地缺失 onnxruntime.dll 时不再尝试加载，避免卡在系统加载器里。
- **滚动导航并入通用工具面板**：取消独立的滚动导航悬浮窗，统一在「通用工具」里使用；置顶窗清单、capabilities 与自有窗口判定三处同步收敛。
- **长截图控制条自适应**：高度按内容（含警告行）量完再下发，重复尺寸不再重复重排窗口；居中后仍会夹到当前显示器工作区。
- **钉图 OCR 结果窗**：关闭 / 隐藏时立即中止翻译流式请求，不再让后台请求空跑消耗接口额度。
- **设置页 · 磁盘看门狗状态**：常驻后台任务的快照写回带序号，进入页签时的旧读取不会再覆盖较新的状态（此前会一直停在旧值，直到下一次周期检查）。
- **待办**：导入 / 导出 / 删除 / 延后等操作的提示改为带语义色与图标的通知条；一批控件补齐中文 aria-label。
- **失败可见性**：草图保存、文字工具栏复制 / 打开浏览器失败时给出可见提示，不再只有后台日志。

## 修复与稳定性

- 截图原生层的收口做了三重保险：前端 pointerup、钩子左键抬起（用抬起点补最后一帧）、pointercancel 与会话清理；准备失败或未就绪时自动退回 WebView 绘制，最坏情况等于没有这个优化。
- 松手到进入标注之间原生层保持"冻结"，不会闪一下没有遮罩的裸桌面。
- 移除滚动导航独立窗口后，自有窗口判定 / 权限 / 前端窗口表三处保持一致（有源码守卫测试覆盖）。
- 新增 3 条源码守卫测试：会话清理必须拆原生层、钩子喂坐标必须带跟踪门禁、松手必须同时停跟踪与冻结。
