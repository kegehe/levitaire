# Levitaire v0.1.0

Levitaire 首个可分发版本 —— Windows 悬浮工具箱：选中文字即可调出工具栏，快速复制、搜索、翻译、优化、转码、朗读；还集成截图、录屏、快速输入转盘、系统监控、番茄钟。

## 文字工具

- 选中文字浮出工具栏：复制 / 搜索 / 翻译 / AI 优化 / 大小写转换 / 编号 / MD5 / 二维码 / 朗读
- 可配置工具栏按钮、搜索引擎、去重、编号样式、朗读语速与语音等

## 截图 / 录屏

- 区域截图：复制、保存、OCR 识别、钉桌
- GIF / 视频录屏：选区、暂停、多目标窗口捕获
- 支持 Windows OCR 与 PaddleOCR 双引擎

## 快速输入

- 一键唤起转盘，输入预设词或剪贴板历史
- 支持「点击切换 / 按住」两种触发模式，触发键可自定义

## 系统监控 / 番茄钟

- 实时显示 CPU / 内存 / 磁盘 / 网络的使用悬浮窗
- 番茄专注计时：可自动循环、到点声音提醒

## 其它

- 全局热键（截图 / 录屏）
- 开机自启；深色 / 浅色主题并可自定义主题色
- 在线更新：支持设置页手动检查与启动自动检测，发现新版本会弹出提示

这是 Levitaire 的第一个可分发基线版本。
