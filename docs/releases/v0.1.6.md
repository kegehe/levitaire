# Levitaire v0.1.6

## 主要更新

- **通用工具集新增「窗口置顶」**：点一下把任意其他程序的窗口钉在最前（面板按钮进入点选、`Esc` 退出）。面板内可查看当前置顶清单并逐条 / 一键取消；工具停用或应用退出时会自动把所有窗口还原，不会留下一个「莫名其妙永远在最前面」的窗口。
- **番茄钟并入「时间工具」**：时钟 / 倒计时 / 番茄钟 / 秒表 / 月历收拢为同一个悬浮窗的五个页签，专注与休息自动循环仍在，并新增沙漏可视化与分段计时。旧版独立番茄钟的启用状态与「启动时自动打开」配置会自动迁移，不会丢失。
- **系统监控新增多套布局与曲线**：CPU / 内存 / 网络 / 磁盘 / 电池按可选布局排布，曲线改用更省空间的 Sparkline 绘制，显示密度可按需切换。
- **安装版不再有「网页味」**：关掉 WebView2 自带的右键菜单（刷新 / 另存为 / 打印 / 检查）与 F5、Ctrl+P 一类浏览器快捷键（仅发布版关闭，开发版保留以便调试）；可编辑区域改用应用自绘的文本菜单，剪切 / 复制 / 粘贴 / 全选一个不少。
- **全屏录制新增原生指示层**：屏幕边缘呼吸框 + 录制控制栏直接画在录制范围之外（`WDA_EXCLUDEFROMCAPTURE`），既看得见又不会被录进成片；区域 / 窗口录制沿用原控制栏。
- **滚动导航兼容更多目标**：目标窗口不提供 UIA 滚动接口时，自动改用投递键盘 / 滚轮做相对滚动（到顶到底、翻页、微调），浏览器与资源管理器同样可用。

## 在线更新重做

- **改为「后台静默下载 → 就绪提示 → 点击即装」**：检测到新版本不再立刻弹窗打扰，下载、验签、落盘完成后才提示「新版本已就绪」，点一下即安装。
- **断网也能装**：安装包缓存到 `%APPDATA%/levitaire/updates/pending-<版本>.exe`（先写 `.part` 再改名，文件名一出现就是完整文件），跨重启复用；安装前会用官方签名复核一次。
- **安装器改为静默进度模式**（`installMode: passive`）：只有进度条、无需交互，装完自动重启。
- 下载 / 安装权改由后端裁决，多个入口同时点也不会重复下一遍 96MB 的包；托盘菜单只读本地快照，不再每次右键都联网检查。
- 下载进度按累计字节换算并做了上报节流，不再出现进度长时间停在 0% 或刷屏式更新。

## 修复与稳定性

- **修复「选中文字弹出工具栏后 Ctrl+C / Ctrl+X 失效」**：选区检测会先备份再回滚剪贴板，而回滚时机正好落在用户按下 Ctrl+C 的半秒里，把他刚复制（更糟的是剪切）的内容覆盖掉。现在回滚前必须确认剪贴板里仍是自己写进去的那份内容，目标程序不响应注入按键时一律不回滚。
- **修复悬浮球透明留白吞掉点击**：圆球之外的透明区域过去会吃掉落点其上的鼠标事件（压在下面的便签顶栏、面板、桌面图标全点不动）。现在由后端鼠标钩子按圆形热区直接切换穿透，球外穿透、球内恢复交互，快速点击也不漏。
- **修复浮窗跑出屏幕**：窗口尺寸是量完内容才下发的，贴屏幕右 / 下沿的窗口在内容变高变宽后（日历切视图、监控切全量、便签加行、面板换页、工具栏弹二维码预览）会有一部分跑到工作区外且点不到；现在每次调整尺寸后都会夹回工作区，且这次移动不会被写进位置记忆。
- **修复截图遮罩窗的自激渲染循环**：窗口实例未做记忆化导致相关副作用每次渲染都重跑，实测约 700 次 IPC / 秒且随应用启动常驻空转。
- **修复原生文件对话框被自家窗口盖住**：保存 / 打开对话框（草稿保存、待办导入导出、钉图与长截图保存）不再出现「点了没反应」，对话框打开期间会临时取消置顶并在关闭后恢复。
- **修复「全部取消勾选」存不住**：工具栏功能与启用工具列表在全部关闭后，重开又全选回来；现在空选择与「从未设置过」是两种状态，并存得下来。
- **修复「跟随系统」主题首帧闪一帧浅色**。
- **修复正式版里 ffmpeg 等子进程弹出黑色控制台窗口**（开发模式看不到，只在安装包里出现）。
- 修复面板窗口高度写死导致的大片空白，改为按内容量测并自适应。
- 修复工具面板「全部关闭」关不掉未登记后端开关的工具（通用工具曾如此）。
- 修复程序性移动窗口会污染位置记忆，导致窗口位置逐步漂移。

## 工程化

- 前端新增 55 个测试文件 / 1073 项用例，全部通过；CI 继续跑 typecheck / lint / Vitest / clippy / cargo test。
- 为易回归的链路补了源码级守卫：子进程必须隐藏控制台启动、文件对话框必须先取消置顶、剪贴板回滚必须带序号守卫、窗口实例必须记忆化、自有窗口判定必须单一来源等。
- 开发文档新增 20 余条最佳实践（浮窗最小宽度、面板高度自适应、程序性移动与位置记忆、跨窗口并发裁决等）。
