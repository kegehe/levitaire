# Levitaire v0.1.5

## 主要更新

- 悬浮工具面板支持分组：按「文字工具 / 屏幕工具 / 系统工具」分段展示；鼠标悬停卡片即可看到该工具的用途说明。拖拽排序限定在同一分组内，避免跨组错位。
- 通用工具取色增强：取色后可直接查看并一键复制 `rgb(r, g, b)`，同时保留 HEX 复制；最近使用的颜色会写入本地，重启后仍可复用。

## 修复与稳定性

- **修复便利贴「新建后卡死、重启后整个应用无响应」**：所有会创建窗口的命令改为 `async`（同步命令会在 Windows 主线程的 WebView2 回调内重入建窗而永久死锁），并给便签窗口的「存在性检查 + 创建」加锁串行化；恢复循环改为单条容错，避免一张失败拖垮其余便签。此前失败的便签状态会被持久化，导致每次启动都复现。
- 修复快速输入转盘在窗口被销毁后重新启用时的同类死锁。
- 修复截图缓存预览、长截图预览与描稿背景的卡顿：全屏级别的 PNG 编码移出主线程与共享锁，界面在编码期间不再冻结。
- 修复在线更新下载进度长期停留在 0%：下载回调给出的是单次分块长度而非累计值，现按累计字节换算百分比。
- 为更新下载补充连接超时与读空闲超时，并开启 Windows 系统代理支持；代理未生效或链路中断时不再无限等待。
- 统一更新安装路径：设置页与右键菜单改走后端下载通道，右键菜单在下载期间就地显示进度，不再「点完毫无反馈」。

## 工程化

- 清理取色功能迁移后遗留的孤立样式与未注册的占位组件。
- 补充面板分组、取色历史与更新链路的单元测试。
- 开发文档新增两条最佳实践：「建窗命令必须 `async`」「更新下载统一走后端」。
