# Levitaire v0.1.7

## 主要更新

- **新增「系统清理」工具**（默认关闭，需在设置 / 工具面板中开启）：一整套「先看清、再动手」的磁盘清理能力 —— 扫描 → 逐项说明会删什么 → 勾选 → 执行，全程可解释、可回退。
  - **分级可勾选、每项写明后果**：用户临时文件（仅 7 天前、未被占用）、缩略图与图标缓存、崩溃转储、显卡着色器缓存、npm / pnpm / pip / Yarn / Go / NuGet / Playwright 缓存、Levitaire 更新包缓存等；回收站**默认不勾选**，执行前二次确认。
  - **安全保证**：占用中的文件一律跳过，绝不硬删；红线目录按运行时派生（不跟随 junction / 符号链接）；系统盘、组件存储（WinSxS）等绝不清理；未扫描的勾选项不允许执行清理。
  - **隔离区（可恢复的删除）**：不合规或属于用户数据的目录不永久删除，只先搬进隔离区，支持恢复 / 彻底删除 / 清空，保留期可选 0 / 7 / 14 / 30 天（0 = 不自动清理）。
  - **「不建议清理」专区**：主动列出 WinSxS、MSI 修复缓存、驱动仓库、休眠 / 页面文件、系统还原点等「看着大但不该删」的目录，逐条给出原因，且不提供清理入口。
  - **空间分析**：可对固定卷做只读扫描，把目录分成「在增长」和「占用最大」两栏报出，看中的目录只能放入隔离区；支持选择卷与报告深度、随时取消、手工添加任意目录。
  - **失控看门狗**（默认关闭）：按周期自动比对快照，把「同时够大且增长够快」的目录浮出来告警，**只发通知、不删任何东西**。
  - **清理审计日志**：记录「删了什么、跳过了什么、为什么」，只存本机、绝不上传，可查看 / 筛选 / 导出，也可一键清空（二次确认）。
- **托盘右键菜单新增「重启应用」**：卡顿时一键拉起干净进程；退出前会正确还原系统光标与窗口置顶等系统级状态。
- **截图标注「画完还能改」**：切到「移动」工具即可直接命中已画标注 —— 整体拖动、矩形类的四边四角缩放、箭头两端拖动；鼠标滚轮可连续调节选中标注的线宽（一次滚轮爆发合并为一步撤销）。
- **截图标注各记各的样式**：矩形 / 箭头 / 画笔 / 文字 / 序号 / 马赛克各自记忆颜色与线宽，互不干扰；线宽改为 1–32 连续可调（在工具栏圆点处滚轮或方向键）；「自动配色」仅对文字 / 序号显示。
- **快速输入转盘支持二级子转盘**：预设片段可配置子项（分组），在转盘上点击或按住松开父级扇区即整盘展开子级；`Esc`、点击圆心死区或按住死区松开可返回上一级，根级则关闭。中心改用胶囊标签完整展示当前高亮项。
- **快速输入转盘音效反馈**（默认关闭）：唤出 / 切扇区 / 确认 / 取消四种音效，可在设置中开关、选择风格、调节音量并试听；切扇区音做了限流，快速划动不叠音。设置页同时支持编辑预设片段的子项（增删、拖拽排序）。
- **便利贴可手动调整大小**：拖右下角纸角手柄（或窗口边）改变尺寸并记忆；双击纸角恢复「宽度固定、高度随内容」的自动模式。
- **便利贴支持图片**：可把本地图片文件拖入便签（PNG / JPG / GIF / BMP，统一转码为 PNG 落盘）；右键便签里的图片弹出「复制图片 / 删除图片」。
- **文本「清除」规则增强**：`清除字母 / 数字 / 中文` 改用 Unicode 属性，可清除全角字母、带圈数字 ①②、罗马数字、扩展区汉字等，并连带清除组合附加符号。
- **「一键恢复默认位置」覆盖更多窗口**：新增对「系统清理面板」与「便利贴管理窗」的恢复入口。

## 修复与稳定性

- **托盘右键菜单「闪一下就没」**：重新获焦时撤销上一次失焦排下的隐藏定时器，菜单不再刚打开就被自己关掉（更新下载期间反复右键尤其明显）。
- **快速输入转盘在多显示器 / 非 100% 缩放下被裁成方形**：每次唤出按「光标所在显示器」的 DPI 重新下发窗口物理尺寸。
- **拖拽选区后文字工具栏「点击丢失 / 穿透迟钝」**：把耗时秒级的选区检测链移出钩子事件的单消费线程，改为独立线程 + 在飞互斥，并丢弃已被新操作顶掉的过期结果。
- **取色笔 / 置顶准星可能永久卡住系统指针**：光标还原扩展到「更新安装」与「应用退出兜底」两条路径，锁中毒时也不再提前返回。
- **多个悬浮窗在窗口销毁后 `Alt+F4` 直接关窗**：设置、工具配置、面板、时间、待办、便利贴管理在窗口 `Destroyed` 时复位关闭拦截注册。
- **便利贴位置漂移**：位置记忆抑制覆盖便利贴自己的落盘入口，内容变高被夹回后不再被永久记住。
- **置顶清单残留「死条目」**：用户自行关闭被置顶窗口后，读取 / 推送清单时回收已失效条目。
- **便利贴图片稳健性**：图片格式一律按字节内容判定并统一转码为 PNG（修复「复制到剪贴板」失败）；导入 / 删除图片走严格路径校验，堵住越界删除；不支持的图片类型给出明确提示而非静默插入。
- **读取失败不再伪装成「空的 / 为 0」**：隔离区、账目、便利贴列表读取失败时显示「读取失败」并提供重试，而不是「还没有数据」。
- **截图相关小修复**：智能窗口模式控件排除范围改为去重下发（原先拖框时每帧发一次 IPC）；截图会话启动不再白等一个 500ms 心跳周期。

## 工程化

- **安装包体积大幅下降**：`ffmpeg.exe` 改为精简构建（约 230 MB → 约 4 MB），仅保留录制链路所需的解码 / 编码 / 封装 / 裁剪组件，产出的 MP4 经逐像素比对与原版完全一致。NSIS 安装包由 92 MB 降至 **37 MB**，安装后占用由约 305 MB 降至约 **77 MB**。重建脚本见 `scripts/build-ffmpeg-lite.sh`。
- **安装器多语言**：NSIS 安装器支持简体中文 / 英文界面，WiX 增加 zh-CN 本地化。
- **依赖与能力调整**：`image` 新增 `jpeg` / `bmp` 特性；`windows` 新增 `Win32_Storage_FileSystem`（清理工具的 FS 级操作）与 `Win32_UI_HiDpi`；capabilities 新增 `system-cleaner-overlay` 窗口与 `core:window:allow-start-resize-dragging`。
- **测试与守卫**：新增系统清理安全护栏、清理配置、标注编辑、便利贴真实 DOM、托盘菜单失焦隐藏、窗口位置目标等契约 / 回归用例；`cargo test` 612 项、前端 1232 项全部通过。
- **仓库卫生**：`.gitignore` 忽略 `*.bak` / `*.orig` / `*.rej` / `*_bak` 等调试残留；开发者文档补充便利贴尺寸与图片、右键接管、清理工具安全约定等实现规范。
