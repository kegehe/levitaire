# Levitaire v0.1.1

## 主要更新

- 新增长截图功能：支持自动滚动、实时预览和独立的截图控制栏。
- 新增手绘工具：支持画笔、橡皮擦、颜色、线宽、撤销、重做、清空和保存。
- 新增右键菜单，并完善截图标注流程。
- 优化悬浮球、工具栏、窗口定位和截图目标识别，工具关闭后可可靠恢复原应用状态。
- 新增可配置的手绘快捷键，并改进快捷输入、番茄钟、录屏、OCR 和在线更新体验。
- Windows 安装包内置 PaddleOCR 资源，支持离线 OCR。

## 修复与稳定性

- 修复使用 `Esc` 或原生关闭按钮结束截图、录屏、手绘和长截图时的清理竞态。
- 修复捕获完成后工具窗口焦点和可见状态未正确恢复的问题。
- 修复从其他应用启动工具时工具栏和悬浮球的交互边界情况。
- 为截图、手绘、设置和番茄钟交互补充回归测试。
