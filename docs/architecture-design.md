# Windows 悬浮工具 - 架构设计文档

## 1. 项目概述

### 1.1 项目目标
开发一个Windows悬浮工具，实现选中文字后在文字下方显示工具栏，支持剪切和复制功能。架构设计要便于后续扩展其他功能（如AI分析等）。

### 1.2 核心功能
- 监听全局文字选择事件
- 在选中文字下方显示悬浮工具栏
- 支持剪切和复制操作
- 可扩展的插件架构

---

## 2. 技术栈选择

### 2.1 技术栈：Rust + Tauri

**选择理由：**

| 特性 | 说明 |
|------|------|
| **性能优秀** | 原生编译，启动快，内存占用低 |
| **内存安全** | Rust 所有权机制避免内存泄漏 |
| **跨平台** | 未来可扩展到 macOS/Linux |
| **UI 灵活** | HTML/CSS/JS 开发 UI，降低前端门槛 |
| **生态成熟** | Tauri 框架稳定，社区活跃 |

### 2.2 技术栈详情

| 层级 | 技术 | 用途 |
|------|------|------|
| **后端** | Rust | 核心业务逻辑、系统 API 调用 |
| **前端** | HTML/CSS/JS | UI 界面（通过 Tauri WebView） |
| **框架** | Tauri | 应用框架，桥接前后端 |
| **Windows API** | windows-rs | 系统钩子、UI Automation |
| **构建** | Cargo | Rust 包管理 |

## 4. 核心模块设计

### 4.1 系统钩子模块 (Hook Manager)

**功能：**
- 监听全局鼠标事件（鼠标释放时检测文字选择）
- 监听全局键盘事件（快捷键支持）

**技术实现：**
- 使用 `SetWindowsHookEx` 安装鼠标钩子
- 使用 `WH_MOUSE_LL` 监听鼠标释放事件
- 钩子回调中触发文字选择检测

### 4.2 文字选择检测模块 (Text Selection)

**功能：**
- 检测当前选中的文字
- 获取选中文字的位置信息
- 支持多种应用程序的文字选择

**技术方案：**

**方案 A：UI Automation（推荐）**
- 使用 Windows UI Automation API
- 获取 `TextPattern` 中的选中文字
- 获取文字的边界矩形位置

**方案 B：剪贴板监听（备选）**
- 模拟 Ctrl+C 复制
- 读取剪贴板内容
- 恢复原始剪贴板

### 4.3 悬浮工具栏模块 (Floating Toolbar)

**功能：**
- 显示悬浮工具栏
- 支持动画效果
- 响应用户操作

**UI 设计：**
- 使用 HTML/CSS 构建工具栏
- 支持主题切换（暗色/亮色）
- 支持动画显示/隐藏

### 4.4 剪贴板管理模块 (Clipboard Manager)

**功能：**
- 复制文字到剪贴板
- 剪切文字（复制 + 删除）
- 读取剪贴板内容

### 4.5 插件系统模块 (Plugin System)

**功能：**
- 管理插件的加载和卸载
- 提供插件接口
- 支持动态扩展

**插件类型：**
- 剪切复制插件（内置）
- AI 分析插件（扩展）
- 翻译插件（扩展）

## 7. 扩展性设计

### 7.1 插件扩展

**添加新插件的步骤：**
1. 在 `src-tauri/src/plugins/builtin/` 创建新模块
2. 实现 `Plugin` trait
3. 在插件管理器中注册
4. 前端会自动显示新插件按钮

**示例：AI 分析插件**
- 调用外部 AI API（如 OpenAI）
- 分析选中的文字
- 返回分析结果

### 7.2 主题扩展

**支持自定义主题：**
- 使用 CSS 变量定义主题色
- 支持暗色/亮色主题切换
- 可扩展自定义主题

### 7.3 快捷键扩展

**支持自定义快捷键：**
- 全局快捷键注册
- 可配置的快捷键映射

## 8. 技术实现要点

### 8.1 Windows API 调用

**使用 windows-rs crate：**
- 调用 `SetWindowsHookEx` 安装钩子
- 调用 UI Automation API 获取文字
- 调用剪贴板 API 进行复制/剪切

### 8.2 Tauri 命令

**后端暴露的命令：**
- `get_selected_text` - 获取选中的文字
- `copy_text` - 复制文字到剪贴板
- `cut_text` - 剪切文字
- `show_toolbar` - 显示工具栏
- `hide_toolbar` - 隐藏工具栏
- `execute_plugin` - 执行插件

### 8.3 窗口管理

**多窗口设计：**
- 主窗口：设置界面（可隐藏）
- 工具栏窗口：悬浮工具栏（无边框、透明背景）

## 10. 总结

本架构设计采用 **Rust + Tauri** 技术栈，具有以下优势：

- ✅ **高性能**：Rust 原生编译，响应迅速
- ✅ **内存安全**：Rust 所有权机制避免内存问题
- ✅ **跨平台**：未来可扩展到其他操作系统
- ✅ **UI 灵活**：HTML/CSS/JS 开发 UI，易于美化
- ✅ **可扩展**：插件系统支持功能扩展

核心模块包括：
1. **系统钩子模块**：监听系统事件
2. **文字选择检测模块**：获取选中文字
3. **悬浮工具栏模块**：显示和交互
4. **插件管理模块**：功能扩展

后续可以在此基础上扩展 AI 分析、翻译、搜索等高级功能。
