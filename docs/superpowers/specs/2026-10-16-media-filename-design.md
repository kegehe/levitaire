# 媒体保存文件名设计

## 目标

普通截图、长截图和录屏保存时自动生成包含本地时间与毫秒的默认文件名，减少重复改名并降低覆盖风险。

## 方案

在 Rust `commands` 模块增加共享命名工具，由后端统一生成保存对话框默认名和配置目录中的自动保存名。格式为 `{kind}_YYYYMMDD_HHmmss_SSS.{ext}`，其中 `kind` 分别为 `screenshot`、`long_screenshot`、`recording`。自动保存目录中若目标已存在，则追加 `_2`、`_3` 等序号；保存对话框仍允许用户修改名称。

## 范围

- 普通截图 PNG
- 长截图 PNG
- 录屏 GIF
- 录屏 MP4

不改变保存目录配置、复制、钉图和预览流程。前端继续传入媒体数据与扩展名，后端负责默认名。

## 验证

增加命名格式、扩展名规范化和重名后缀的 Rust 单元测试；运行 `cargo test` 相关测试、`npm run typecheck` 和前端测试。
