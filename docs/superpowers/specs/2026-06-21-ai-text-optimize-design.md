# AI 文本优化功能设计

## 概述

在选中文本的浮动工具栏中添加 AI 优化功能。用户选中文本后，可通过工具栏的优化按钮选择预设模式（润色、正式化、简洁化、翻译），AI 优化后预览结果，确认后替换原始文本。

## 交互流程

工具栏采用状态机管理，共 5 种状态：

```
[默认态] ──点击优化──→ [模式选择态] ──选择模式──→ [加载态] ──AI返回──→ [预览态]
   ↑                                                      │
   └──────────────取消/确认替换后──────────────────────────┘
   └──────────────────────AI失败──────────→ [错误态] ──3秒/点击──→ [默认态]
```

| 状态 | 工具栏内容 | 操作 |
|------|-----------|------|
| **默认态** | `[📋 复制] [✨ 优化]` | 点击优化进入模式选择 |
| **模式选择态** | `[←返回] [✨润色] [🎩正式化] [✂️简洁化] [🌐翻译]` | 选择模式后进入加载态 |
| **加载态** | `[🔄 优化中...]` 旋转动画 | 等待 AI 返回；可取消回到默认态 |
| **预览态** | 优化后文本预览区 + `[✓ 替换] [✗ 取消]` | 确认后替换原文并回到默认态 |
| **错误态** | 错误信息 + `[↩ 返回]` | 点击返回或 3 秒后自动回到默认态 |

### 未配置处理

点击优化时检查 AI 配置（通过 `get_ai_config` 命令），若 API Key 为空：
- 显示提示"请先配置 AI"
- 点击提示跳转到设置窗口（显示 settings 窗口）

## 预设模式

| 模式 | 图标 | 标签 | System Prompt |
|------|------|------|---------------|
| **润色** | ✨ | 润色 | "你是一个文本润色专家。请润色和优化以下文本，使其更流畅、更自然、更易读，保持原意不变。只返回润色后的文本，不要添加任何解释或前缀。" |
| **正式化** | 🎩 | 正式化 | "你是一个文本正式化专家。请将以下文本改写为更正式、更专业的风格，适合商务或学术场景，保持原意不变。只返回改写后的文本，不要添加任何解释或前缀。" |
| **简洁化** | ✂️ | 简洁化 | "你是一个文本精简专家。请将以下文本精简为更简洁、更紧凑的版本，去除冗余表达，保持核心信息不变。只返回精简后的文本，不要添加任何解释或前缀。" |
| **翻译** | 🌐 | 翻译 | "你是一个翻译专家。请将以下文本翻译为中文（如果原文是中文则翻译为英文），保持原文的语气和风格。只返回翻译后的文本，不要添加任何解释或前缀。" |

Prompt 设计原则：
- 明确要求"只返回结果文本，不添加解释"，确保 AI 输出可直接用于替换
- 翻译模式自动检测语言方向（中→英 / 英→中）
- 模式定义在前端常量文件中，方便后续扩展

## 后端改动

### 新增 Tauri 命令：`replace_selection`

```rust
#[tauri::command]
async fn replace_selection(text: String) -> Result<(), String>
```

实现思路：
1. 获取暂存的选区信息（窗口句柄、选区范围）
2. 使用 UI Automation 的 `TextPattern` 重新定位选区
3. 调用 `ValuePattern::SetValue()` 或发送 `EM_REPLACESEL` 替换选中内容
4. 如果选区已失效，返回错误

选区暂存机制：
- 在 `selection-found` 事件触发时，后端将 `SelectionInfo` 及额外的窗口/选区信息存入全局状态
- 替换时使用暂存信息定位目标
- 每次新的 `selection-found` 覆盖旧的暂存

### 修改 AI 调用命令

扩展 `call_ai` 支持 `system_prompt`：

```rust
#[tauri::command]
async fn call_ai(prompt: String, system_prompt: Option<String>) -> Result<AiResponse, String>
```

`AiService::call()` 相应扩展，在请求体中添加 `system` 字段。

### 设置页 AI 配置

在 `Settings.tsx` 中新增 AI 配置区域：
- API Key 输入框（密码类型，可切换显示）
- Base URL 输入框（默认 `https://api.anthropic.com`）
- Model 输入框（默认 `claude-sonnet-4-20250514`）
- 保存按钮调用 `update_ai_config`

## 前端组件改动

### FloatingToolbar.tsx 状态机

```typescript
type ToolbarState = 'default' | 'mode-select' | 'loading' | 'preview' | 'error';
```

组件状态：
- `state: ToolbarState` — 当前状态
- `optimizedText: string` — AI 返回的优化文本
- `selectedMode: OptimizeMode | null` — 当前选中的优化模式
- `errorMessage: string` — 错误信息

### 工具栏窗口大小动态调整

| 状态 | 窗口大小 |
|------|---------|
| 默认态 | 200×50 |
| 模式选择态 | 280×50 |
| 加载态 | 200×50 |
| 预览态 | 最大 400×200，文本超出时滚动 |
| 错误态 | 300×50 |

通过 Tauri 的 `win.setSize()` API 动态调整。

### 新增文件

| 文件 | 用途 |
|------|------|
| `src/constants/optimizeModes.ts` | 预设模式定义（图标、标签、system prompt） |
| `src/hooks/useAiOptimize.ts` | 自定义 Hook，封装 AI 调用逻辑和状态管理 |

### CSS 改动

- `FloatingToolbar.css` — 新增模式选择、预览区、加载动画、错误提示的样式
- `global.css` — 新增预览态相关的 CSS 变量

## 错误处理

| 场景 | 处理方式 |
|------|---------|
| AI 未配置（无 API Key） | 提示"请先配置 AI"，可跳转设置页 |
| AI 调用失败（网络/认证错误） | 错误态显示具体错误信息，3 秒后回到默认态 |
| 替换失败（选区已失效） | 错误态提示"无法替换，请重新选中文本" |
| AI 返回空内容 | 错误态提示"AI 未返回有效内容" |

## 不在范围内

- 流式输出（AI 逐字返回）— 后续可扩展
- 自定义 prompt 编辑 — 后续可扩展
- 优化历史记录 — 后续可扩展
- 快捷键触发优化 — 后续可扩展
